# Logos dos clientes

Coloque aqui o logo de cada cliente com o nome `<slug-do-cliente>.png` — por exemplo,
`ponto-car.png` para o cliente `ponto-car`.

- Formato PNG, de preferência com **fundo transparente**.
- É colado automaticamente no canto superior direito das imagens geradas pelo Agente de
  Design — se o arquivo não existir para um cliente, a imagem é gerada normalmente, sem
  logo (recurso totalmente opcional).
- Não precisa mexer em nenhum código para ativar — basta o arquivo existir com o nome
  certo nesta pasta.
